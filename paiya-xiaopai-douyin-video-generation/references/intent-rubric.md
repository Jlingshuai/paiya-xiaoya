## 1. 判定顺序

| 顺序 | 判定 | 命中条件 | 结果 |
|---|---|---|---|
| ① | 流程续接 | 已在脚本链路（等补字段 / 等选版 / 改写中） | `continue` / `rewrite` |
| ② | 显式拒绝 | 不用写 / 先不生成 / 算了 | `exit` |
| ③ | 形态路由 | 小红书图文信号 → 反向转交；形态冲突或只有「脚本」→ 确认一次 | `handoff_article` / `confirm_modality` |
| ④ | 评估诉求 | 诊断词且无创作动词 | `evaluate` |
| ⑤ | 方法论提问 | 起号 / 完播 / 限流 / 投流 | `chat` |
| ⑥ | 打分 | 以上均未命中 | 按第 3–4 节 |

## 2. 意图与形态

| 意图 | 含义 | 后续 |
|---|---|---|
| `generate` | 要一条或多条抖音视频脚本 | 阶段一或阶段二 |
| `rewrite` | 改某一版的某镜/某秒 | 阶段六 |
| `evaluate` | 诊断已有视频，不重写 | 出评估报告 |
| `chat` | 方法论、闲聊 | 日常问答 |
| `handoff_article` | 实际要的是小红书图文 | 转交图文技能 |
| `confirm_modality` | 图文还是视频说不清 | 问一次 |

形态判定：

| 命中 | modality | 结果 |
|---|---|---|
| 抖音 | video / 抖音 | 本技能 |
| 小红书 + 视频词 | video / 小红书 | 说明本期只覆盖抖音 |
| 小红书 / 图文 / 笔记 | article / 小红书 | `handoff_article` |
| 视频词 + 图文词、无平台 | ambiguous | `confirm_modality` |
| 只有「脚本」 | unspecified | `confirm_modality` |

**强形态例外**：出现「分镜 / 口播稿 / 视频脚本」且有创作动词时，即使没有「抖音」二字也直接触发——这些词在 MCN 语境里几乎只指视频。

## 3. 三层打分

| 层 | 信号 | 分值 |
|---|---|---|
| L1 | 抖音平台词 | +20 |
| L1 | 创作动词（写/生成/拍/出/改） | +20 |
| L1 | 视频对象（视频脚本/分镜/口播稿/短视频） | +15 |
| L1 | brief 附件 | +25 |
| L1 | 商单词（商单/报备/挂车/brief） | +20 |
| L1 | 时长或条数（30秒/三条/三版） | +10 |
| L2 | 创作动词族（每命中 +8，上限 16） | ≤16 |
| L2 | 内容要素词（≥2 个，每 2 个 +3） | ≤9 |
| L2 | 平台词密度（≥2 组） | +5 |
| 扣分 | 方法论 | −25 |
| 扣分 | 诊断且无创作动词 | −20 |
| 扣分 | 寒暄 | −40 |
| 扣分 | 只有平台词、无动作无对象 | −10 |

L1 封顶 65，L2 封顶 30，总分封顶 95。

## 4. 阈值

- ≥70 → `generate`
- 40–69 → LLM 二判（`temperature=0`，只答是/否）
- <40 → `chat`
- 例外：带 brief 的商单落在 40–69 直接触发；强形态词 + 创作动词直接触发。

**为什么阈值仍取 70**：视频脚本误触发后会生成一整张分镜表，返工成本高于图文；宁可多问一句，也不要把「完播率怎么提」写成 30 秒分镜。

## 5. 正负例（实测）

| # | 输入 | 分数 | 判定 |
|---|---|---|---|
| 1 | 帮我写个30秒抖音口播脚本，山栖咖啡液 | 78 | generate |
| 2 | 按这个 brief 出三条抖音视频脚本（带附件） | 70 | generate |
| 3 | 帮我改一下第二版第3秒到第5秒的画面（链路中） | 38 | rewrite |
| 4 | 抖音完播率怎么提升 | 0 | chat |
| 5 | 帮我看看这条视频为什么没流量 | 0 | evaluate |
| 6 | 在吗 | 0 | chat |
| 7 | 帮我写篇小红书笔记，种草这个咖啡 | 28 | handoff_article |
| 8 | 写个分镜 | 43 | generate（强形态例外） |
| 9 | 帮我写篇脚本 | 43 | confirm_modality |
| 10 | 今天好困 | 0 | chat |

## 6. 校准

1. 改权重后先跑 `python3 scripts/intent_score.py --eval references/video-cases.jsonl`，要求 10/10。
2. 新增负例优先补：方法论文、诊断文、图文请求、只提平台不提产出。
3. 阈值调整必须同时回归图文技能，避免两边对同一句话给出相反判定。
