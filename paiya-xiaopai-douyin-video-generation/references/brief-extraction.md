# Brief 解析（视频版）

视频 brief 与图文 brief 的字段重叠约 80%，差异集中在**交付形态**：时长、比例、口播人、镜头节奏、挂车与报备。解析时两者都要抽。

## 1. 读取方式

| 输入 | 工具 |
|---|---|
| PDF | `pdf` Skill |
| Word / DOCX | `word` Skill |
| Excel / CSV | `sheet` Skill |
| PPT | `ppt` Skill |
| 图片 / 截图 | 先 OCR，逐字校对数字 |
| 纯文本 / 聊天粘贴 | 直接读 |
| 飞书 / 腾讯 / 企业微信 / 钉钉链接 | 先判域名，再选对应读取方式 |

## 2. 字段表

| 字段 | 必填 | 缺失处理 | 视频特有 |
|---|---|---|---|
| 品牌 | 是 | 追问 | — |
| 产品 | 是 | 追问 | — |
| 品类 | 是 | 可从产品推断，需确认 | — |
| 核心卖点 1–3 | 是 | 追问，最多问 3 项 | — |
| 目标人群 | 是 | 可从画像推断，需标注 | — |
| 价格机制 | 否 | 不写价格 | 必须写「活动期」 |
| 规格成分 | 否 | 不写成分 | — |
| 使用场景 | 否 | 从画像补，标注来源 | — |
| 竞品禁区 | 否 | 默认不贬低任何品牌 | — |
| 内容要求 | 否 | 用默认节奏 | **必抽：时长、比例、口播人、挂车、报备** |
| 禁用项 | 否 | 用通用违禁词表 + 品类加严 | 视频另查 BGM 授权 |

## 3. 解析流程

1. **通读一遍**，先标出所有数字与时间承诺（时长、活动期、限量）。
2. **抽字段**，每个字段保留原文片段（10–20 字），便于回溯。
3. **判形态**：写清时长档（15/30/60s）、比例（9:16 默认）、是否口播、是否挂车。
4. **出事实卡**：表格展示，字段 / 值 / 原文片段 / 是否缺失。
5. **确认门**：用户确认后才进入生成。只改被点名的字段，不重跑整份解析。

## 4. 缺失追问话术

一次最多问 3 项，按影响排序：

> 这份 brief 里还差三样，补上我就能直接写分镜：
> 1）视频要做多长（15 / 30 / 60 秒）？
> 2）你自己出镜口播，还是纯画面 + 字幕？
> 3）有没有必须出现的画面或场景（比如冲泡特写）？

用户说「你定」→ 用默认 30s、真人口播、9:16，并在事实卡标注「默认值」。

## 5. 完全没有产品信息

不生成任何内容，直接请用户上传 brief 或贴文字。不得自行编一个产品，也不得静默降级成日常创作。

## 6. 冲突处理

- brief 说 30s，用户说 15s → 以用户当轮为准，并在事实卡标注变更来源。
- brief 要求「提神醒脑」，平台规则禁止 → 不写功效，改用场景描述，向用户说明原因。
- 价格与活动期不一致 → 以 brief 为准，提示用户核对。
