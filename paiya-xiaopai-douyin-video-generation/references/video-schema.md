## 1. 单版脚本结构

每一版是一段可直接照着拍的表格，不是散文。固定顺序：

```markdown
### V1｜口播测评（33 秒）

- **定位**：给谁看、解决什么、为什么信
- **时长 / 比例**：30s（28–32s）｜9:16 竖屏
- **前 3 秒钩子**：具体写清画面 + 第一句台词
- **口播总字数**：xx 字（上限 150）
- **卖点落点**：S2 价格 / S4 成分 / S6 冲泡

| 镜号 | 时间码 | 时长 | 景别 | 画面 | 台词 / 口播 | 字幕 | 音效 / BGM | 转场 |
|---|---|---|---|---|---|---|---|---|
| S1 | 0-3s | 3s | 近景 | ... | ... | ... | ... | 硬切 |
| S2 | 3-6s | 3s | 特写 | ... | ... | ... | ... | 硬切 |

- **拍摄清单**：场景、道具、人员、光位
- **事实引用**：列出用到的 brief 事实与数字
```

缺任何一项都算结构不完整，质检会标 BLOCK。

## 2. 分镜表字段

| 字段 | 要求 | 常见错误 |
|---|---|---|
| 镜号 | `S1` 起连续编号，不跳号 | 出现 S0 或重复镜号 |
| 时间码 | `起-止s`，从 0 开始，与上一镜无缝 | 时间码重叠、留空档 |
| 时长 | `3s`，单镜 ≤5 秒 | 一镜写 8 秒（完播率杀手） |
| 景别 | 远景／全景／中景／近景／特写 | 写「正常」「随便」 |
| 画面 | 谁、在哪、做什么，可执行 | 写「氛围感」「高级感」 |
| 台词 / 口播 | 逐字可念，口语短句 | 书面长句、括号内心戏 |
| 字幕 | 与台词一致，或承担画面信息 | 字幕与台词两套说法 |
| 音效 / BGM | 曲库可用、环境音或音效 | 「热门 BGM」无具体指向 |
| 转场 | 硬切／叠化／甩镜等 | 每镜都写「炫酷转场」 |

## 3. 锚点体系

| 锚点 | 指代 | 改写粒度 |
|---|---|---|
| `V{n}-HOOK` | 前 3 秒钩子（画面 + 首句台词） | 换钩子类型 |
| `V{n}-COVER` | 标题 / 封面字 | 换标题、换封面文案 |
| `V{n}-S{k}` | 第 k 个镜头整行 | 换画面、换台词、换景别 |
| `V{n}-S{k}.line` | 该镜的台词单元格 | 只改口播 |
| `V{n}-S{k}.visual` | 该镜的画面单元格 | 只改画面 |
| `V{n}-CAP` | 全片字幕策略 | 改字幕风格或信息分工 |

锚点必须写进成品卡。用户说「第二个视频第 3 秒到第 5 秒」，先按时间码定位到具体镜号，再改那一行，不重写整段。

## 4. 用户说法 → 锚点映射

| 用户说法 | 实际要改的锚点 |
|---|---|
| 改第一个的标题 | `V1-COVER` |
| 开头再抓人一点 | `V1-HOOK`（只改 S1，不动 S2 之后） |
| 第 3 秒到第 5 秒人物表情丰富点 | 时间码落在哪一镜就改 `V{k}-S{n}.visual` |
| 第二个视频的口播太快 | 该版所有 `S{k}.line` 缩短，同步压字数 |
| 把价格提到前面 | 把价格句迁到更早的镜头，标注移动而非新增 |
| 换个 BGM | 该版「音效 / BGM」列整列替换 |
| 结尾再软一点 | 最后一镜台词与字幕 |

**定位不到**（例如「第 8 秒」落在空档、或用户说的版本不存在）→ 回问一句，不猜。

## 5. 三版策略骨架

| 版本 | 叙事形式 | 口播占比 | 前 3 秒手法 | 适合的卖点 |
|---|---|---|---|---|
| V1 | 真人口播测评 | 70% 以上 | 直接抛数字或结论 | 价格、成分 |
| V2 | 剧情演绎（冲突 / 误会） | 30–50% | 第三方提问或冲突台词 | 场景、性价比 |
| V3 | 沉浸式跟拍 / 动作流 | ≤10%（可无口播） | 动作或声音先行 | 冲泡体验、质感 |

**每一版必须能单独成立**：不依赖另外两版做对比，用户只投一版也能跑。

---

## 6. 互斥硬约束

1. 三版前 3 秒钩子类型不得重复（数字／冲突／动作／提问只能各用一次）。
2. 三版口播占比必须分档（>70% / 30–50% / ≤10%），不允许三版都是口播。
3. 同一开场句式的连续 6 字不得跨版重复。
4. 三版主推卖点不得完全相同：至少各自主推一条不同的卖点。
5. 三版结尾不得都是「价格 + 下单」；V2 或 V3 必须换一种收尾（回扣开头 / 第三方反应 / 动作收尾）。

违反任一条，重写该版，不带病展示。

---

## 7. 时长与字数换算

| 时长 | 镜头数 | 口播上限（5 字/秒） | 建议实际字数（4.2 字/秒） |
|---|---|---|---|
| 15s | 5–8 | 75 | 60–65 |
| 30s | 8–14 | 150 | 120–135 |
| 60s | 15–22 | 300 | 240–270 |

- 单镜不超过 5 秒；超过就拆镜。
- 台词字数按去掉标点后计；字幕字数不计入口播上限，但单屏字幕不超过 18 字。
- 语速可调，但**镜头时长与台词字数必须匹配**：3 秒镜头配 20 字台词念不完，质检会拦。

---

## 8. 事实使用边界

- 价格、成分、工艺、咖啡因、限量数字只能来自 brief / 事实卡。
- brief 没写的认证、检测、获奖、销量，一律不写。
- 推算值必须可复算（如 69 ÷ 10 = 6.9 元/条），并在成品卡「数字人工判定」里写算式。
- 功效词一个都不能碰，包括「提神」这类看似中性的表述。

---

## 9. 版本链

```text
V1（初版）→ V2（初版）→ V3（初版）
V2 → V2.1（改标题）
V2.1 → V2.2（改第 3–5 秒画面）
```

- 只记录被改过的版本，未改版不写链。
- 每轮改写后必须重跑该版质检，结论写进链尾。
