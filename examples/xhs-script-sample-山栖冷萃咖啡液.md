## 三、三版脚本

### V1｜痛点共鸣

- **定位**：打给每天两杯外卖咖啡的早八人，用「6.9 元」一个数字撬动，核心是省钱与减负。
- **标题**：T1 早八人把30块的咖啡戒了；T2 一个月咖啡钱，够我买双鞋；T3 7:40的地铁口，我改喝这个
- **封面**：C 大字「6.9元一杯」＋ 副标「早八自救，不算贵」
- **正文**：
  - **B1** 7:40，地铁口便利店，前面那个人手里一杯 30 块的冰美式，我盯了两秒，还是转身走了。
  - **B2** 不是喝不起。是每天两杯，月底看账单会愣一下。喝的时候爽，付款那下肉疼；下午心跳快，晚上躺床上又担心今天糖超了。一天 60 块，一个月就是 1800，够交半个月房租。
  - **B3** 试过速溶，酸得皱眉，喝完嘴里发涩；买过挂耳，滤纸要洗、水要烧，赶时间根本顾不上，最后全塞在柜子最里面落灰。也买过便利店罐装，甜得像糖水。
  - **B4** 后来同事塞给我一条山栖冷萃咖啡液。撕开倒进冰水，3 秒就化开，不用搅拌。0 糖 0 脂，配料表只有咖啡豆和水；云南日晒豆，12 小时低温冷萃；一条算下来 6.9 元，不到门店的四分之一。冷水热水牛奶都能兑，出差我也带着。
  - **B5** 现在包里常备三条，到工位先冲一杯。口感不比门店差，也不用再为「又花 30 块」纠结，月底账单终于能看懂了。省下的钱没乱花，攒着换了双一直想买的鞋。
  - **B6** 你们一个月咖啡预算多少？评论区报个数，我看看谁比我狠。
- **标签**：H #美食 #咖啡液 #早八打工人 #办公室续命 #平价好物 #减脂期饮品
- **配图**：P1 封面：地铁口手持冰杯，背景是晨光；P2 产品包装与十条装；P3 咖啡液倒入冰水的瞬间；P4 工位桌面，杯子挨着键盘；P5 配料表特写
- **事实引用**：F = 6.9 元/条、0 糖 0 脂、3 秒速溶、云南日晒豆、12 小时冷萃、门店 30 元/杯

### V2｜场景种草

- **定位**：打给下午犯困的办公室人群，用五感细节把「3 秒」写成动作，不堆参数。
- **标题**：T1 15:07，工位飘起咖啡味；T2 下午三点，我在工位冲了杯冰美式；T3 不用下楼，3秒喝到冰美式
- **封面**：C 大字「3秒一杯」＋ 副标「不用下楼，不用等」
- **正文**：
  - **B1** 15:07，第三次合上又打开同一个文档，脑子像糊了一层雾，键盘声都变得很远，连同事叫我都慢了半拍。
  - **B2** 楼下咖啡店要排队，外卖送上来冰都化了，起送费比咖啡还贵；茶水间只有速溶，冲开一股焦苦味，喝两口就放下。想喝口像样的，成本比想象中高。
  - **B3** 抽屉最里面摸出一条山栖冷萃咖啡液，撕开，倒进早上剩下的半杯冰水，杯子里还浮着两块没化完的冰。一条 6.9 元，比楼下那杯便宜太多。
  - **B4** 棕色的液体沉下去，3 秒和冰水融在一起，杯壁起了一层薄雾。不用咖啡机，也不用打奶泡，拿根吸管搅两下就行。第一口是柑橘的酸，后面是坚果的回甘，不涩，也不腻。
  - **B5** 0 糖 0 脂，喝完嘴里是清爽的，不会像奶茶那样腻在嗓子眼里。以前三点必点一杯奶茶，现在换成它，热量这块终于不用反复算。再回到工位，屏幕上的字终于能一行一行往下读。
  - **B6** 你们下午几点最困？我猜是三点，评论区对一下时间。
- **标签**：H #美食 #咖啡 #办公室日常 #下午茶 #打工人 #快手饮品
- **配图**：P1 工位视角：杯子、电脑、便利贴；P2 撕开包装倒进杯子；P3 溶解瞬间特写；P4 窗边自然光下的杯壁水雾；P5 空杯与包装条
- **事实引用**：F = 3 秒速溶、0 糖 0 脂、冷萃工艺

### V3｜测评对比

- **定位**：打给正在做选择的理性派，只比单次成本、便利性、成分三项，主动劝退不适合的人。
- **标题**：T1 咖啡液横评：我只留下了这一条；T2 6.9元 vs 30元，这笔账算给你看；T3 三种咖啡方案，打工人怎么选
- **封面**：C 大字「6.9 vs 30」＋ 副标「一笔一笔算清楚」
- **正文**：
  - **B1** 先说结论：想省钱又要口感，选咖啡液；追求现磨香气和拉花，还是去店里。没有哪种更好，只有哪种更合适你。我把三种常见方案摆在一起，按同一套标准打分。
  - **B2** 我只比三个维度：单次成本、便利性、成分干净程度。这三项直接决定第二天还会不会继续喝；别的花哨指标，对每天赶时间的人意义不大。
  - **B3** 门店美式 30 元一杯，胜在现磨；速溶便宜，但酸涩，还得烧水；山栖一条 6.9 元，冷水、热水、牛奶都能兑，3 秒化开。价格差就摆在这，选哪个看你更在意什么。
  - **B4** 按一天两杯算：门店一个月 1800，咖啡液一个月 414，差价 1386。这笔账我算了三遍，没算错。够买一双不错的鞋，或者一次短途旅行。
  - **B5** 但它不适合两类人：追求油脂和拉花的，以及对咖啡因敏感、下午喝了睡不着的。适合早八、加班、减脂期想喝又怕热量的人。
  - **B6** 你属于哪一种？评论区说一句，我帮你选，也可以说说你常喝的那款。
- **标签**：H #美食 #咖啡测评 #打工人 #平价好物 #减脂期 #咖啡液
- **配图**：P1 三杯并排：门店杯、速溶杯、咖啡液杯；P2 价格标签特写；P3 产品条与包装盒；P4 记账本与计算器；P5 适用场景拼图
- **事实引用**：F = 6.9 元/条、门店 30 元/杯、3 秒速溶、0 糖 0 脂；B4 的月度数字为按单价与每天 2 杯推算，非 brief 原文
