# 合规与质检通用规则

图文与视频共用一张合规底线。分支脚本只实现可自动化的词表与结构检查；语义判断仍由模型逐段复核。

## 1. 硬阻断（命中即 BLOCK）

| 类别 | 词条 / 情形 |
|---|---|
| 绝对化用语 | 最好、最强、最低、最高、第一品牌、全网最低、史上最低、顶级、极致、唯一、永久、彻底、根治、100% 有效、绝对 |
| 功效宣称 | 治疗、治愈、疗效、防癌、抗癌、降血糖、降血压、降血脂、减肥、瘦身、燃脂、排毒、增强免疫力、抗衰老、提神醒脑 |
| 金融承诺 | 稳赚、保本、零风险、无效退款 |
| 站外引流 | 加微信、加 V、vx、VX、私信我、私信领、淘宝搜、链接在评论区、主页有链接、代购、扫码加 |
| 违规暗示 | 内部价、渠道价、员工价、绕过平台、私下交易 |
| 贬低竞品 | 其它品牌都是垃圾、比 XX 难喝、点名拉踩 |
| 未授权背书 | brief 未提供的检测报告、获奖、医生推荐、认证 |

## 2. 需人工确认（WARN）

- 「最」+ 评价词（最划算 / 最推荐 / 最好喝）；
- 百分比断言（90% / 100%）；
- 时长 + 效果承诺（3 天见效 / 立刻不困）；
- 程度副词（超级 / 巨 / 爆炸 / 绝了）；
- 咖啡因体感描述（心慌、睡不着）；
- 竞品品牌名出现，但未贬低。

## 3. 认证与数据口径

「首创」「销量第一」「全球第一」这类表述，必须同时满足：

1. 有认证机构全称；
2. 有统计范围（如全国不含港澳台全渠道）；
3. 有统计截止日（如截至 2026-05-31）；
4. 不写成裸奔的「全网第一」「最好喝」。

示例：

> 经尚普咨询集团市场地位声明书确认，瑞幸是「生椰拿铁首创者」，对比范围为全国（不含港澳台）全渠道；截至 2026-05-31 累计销量超 21 亿杯。

**价格口径**：

- 门店现制价不写死，统一写「APP / 小程序当日实际售价」；
- 零售价必须带规格与活动期（如 125g×18 盒，活动价约 64.9 元/件）；
- 不写「原价 XX，现价 XX」但没有活动期。

## 4. 食品类额外红线

- 不得宣称减肥、减脂、控糖、养胃、健康无害；
- 椰浆、果汁等含天然糖分，不能写成「0 糖」「无糖」；
- 热量数字必须带完整条件（杯型 / 温度 / 豆子 / 浓度 / 糖度），不能简化为「一杯只有 179 大卡」；
- 不把主观感受写成检测结论（「实测 0 卡」「测评 98 分」）。

## 5. 替换建议

| 原表述 | 建议 |
|---|---|
| 最好喝 / 最好用 | 我个人更常喝 / 我回购次数最多 |
| 全网最低 | 我对比到的价格里比较划算的 |
| 100% 有效 | 我自己的感受是 |
| 立刻不困 | 喝完半小时后状态回来了 |
| 减肥 / 瘦身 | 热量上更放心（不承诺减重） |
| 私信我 / 加微信 | 评论区聊 / 主页有整理 |
| 顶级原料 | 写具体事实（云南日晒豆 / 椰肉厚度 > 8mm） |

## 6. 脚本与人工的分工

| 层 | 谁做 | 说明 |
|---|---|---|
| 规则层 | `scripts/xhs_qc.py` / `scripts/video_qc.py` | 词表 + 正则，命中即 BLOCK / WARN |
| 结构层 | 分支脚本 | 图文查锚点与字数；视频查 9 列、时间码、单镜、口播 |
| 覆盖层 | 分支脚本 + 人工 | 卖点、数字白名单、禁用项；数字待核项由模型逐个人工判断 |
| 语义层 | 模型 | 夸大、贬低、虚假对比、恐吓；命中记 WARN |

**任何一层未执行，成品卡不得写「已质检」**，只能写「质检范围：…」。
