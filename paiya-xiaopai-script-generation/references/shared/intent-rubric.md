# 统一意图识别与打分（小红书图文 / 抖音视频）

本文件是 `scripts/intent_score.py` 的规则说明。一个入口同时回答两个问题：

1. 要不要进入脚本生成链路；
2. 如果进入，走小红书图文分支还是抖音视频分支。

## 目录

1. 判定顺序
2. 形态门（最高优先级）
3. 意图与分支
4. 三层打分
5. 阈值与例外
6. 正负例基线
7. 校准方法

---

## 1. 判定顺序

按以下顺序执行，前一步命中即结束，不进入后续打分：

| 顺序 | 判定 | 命中条件 | 结果 |
|---|---|---|---|
| ① | 流程续接 | 已在脚本链路（等补字段 / 等选版 / 改写中） | `continue`；有改动动词 + 指代版本 / 秒数 / 镜号 → `rewrite` |
| ② | 显式拒绝 | 「不用写」「先不生成」「算了」 | `exit` |
| ③ | 形态门 | 见第 2 节 | `generate` + `branch`，或 `confirm_modality` |
| ④ | 评估诉求 | 诊断词且无创作动词 | `evaluate`，只出评估 |
| ⑤ | 方法论提问 | 起号 / 完播率 / 限流 / 违规词 / 几点发 | `chat` |
| ⑥ | 打分 | 以上均未命中 | 按第 4–5 节 |

**为什么形态门放在打分前**：图文正文和视频分镜的产出结构、锚点、质检判据完全不同。先判形态，再决定读哪套 schema；否则一个「抖音口播稿」会按图文分值被误放进图文链路。

---

## 2. 形态门（最高优先级）

**只看本轮用户原话，不继承上下文。**

| 本轮原话命中 | modality | platform | 路由 |
|---|---|---|---|
| 小红书 / 红书 / xhs（无视频词） | `article` | 小红书 | `generate` + `branch=article` |
| 图文 / 笔记 / 封面 / 话题 / 标签（无平台词） | `article` | 小红书 | `generate` + `branch=article` |
| 抖音 / douyin | `video` | 抖音 | `generate` + `branch=video` |
| 视频 / 视频脚本 / 短视频 / 分镜 / 口播稿 / 镜头 / 第 N 秒 / S N | `video` | 抖音 | `generate` + `branch=video` |
| 小红书 + 视频词 | `video` | 小红书 | 视频分支，但如实说明「本期视频只覆盖抖音」 |
| 小红书 + 抖音同时出现 | `ambiguous` | — | `confirm_modality` |
| 抖音 + 图文 / 笔记（本期不支持抖音图文） | `ambiguous` | — | `confirm_modality`，说明本期只覆盖小红书图文 + 抖音视频 |
| 视频词 + 图文词、无平台 | `ambiguous` | — | `confirm_modality` |
| 只有「脚本 / 商单创作 / 生成一篇 / 写篇脚本」等中性词 | `unspecified` | — | `confirm_modality` |

**确认话术只有一句**：

> 要小红书图文笔记，还是视频脚本（抖音）？

**顺序铁律**：

1. 先问平台，答完再问 brief 与红人。
2. 形态确认前不解析 brief、不装配画像、不生成任何正文或分镜。
3. 不根据产品品类（咖啡 → 图文）、品牌、红人赛道、上一轮选择或会话历史推断。
4. 上一轮刚选过图文，新一轮未指定平台，仍要重新确认。

**强形态例外**：出现「分镜 / 口播稿 / 视频脚本 / 短视频」且有创作动词时，即使没有「抖音」二字，也直接走视频分支。这些词在 MCN 语境里几乎没有歧义。

## 3. 意图与分支

| 意图 | 含义 | 后续 |
|---|---|---|
| `generate` | 要生成图文笔记或视频脚本 | 按 `branch` 进入阶段一或阶段二 |
| `llm_check` | 40–69 分，需 LLM 二判 | 二判「是」→ `generate`；「否」→ `chat` |
| `rewrite` | 改已生成版本的某个锚点 / 镜号 / 秒数 | 进入定点改写 |
| `evaluate` | 诊断已有内容，不重写 | 只出评估报告 |
| `chat` | 方法论、平台规则、闲聊 | 日常问答 |
| `confirm_modality` | 图文还是视频说不清 | 只问一次平台 |
| `exit` | 显式拒绝 | 退出技能 |

`branch` 取值：

- `article`：小红书图文笔记；
- `video`：抖音 30 秒分镜（默认）；
- `null`：`chat` / `evaluate` / `rewrite` / `confirm_modality`。

`mode` 是展示用的中文标签：`图文` / `视频` / `商单` / `日常` / `待确认`。

## 4. 三层打分

### 第一层：硬信号（累加，封顶 65）

| 信号 | 命中条件 | 分值 |
|---|---|---|
| `L1.platform` | 小红书 / 红书 / xhs / 抖音 / douyin | +20 |
| `L1.action` | 写 / 生成 / 拍 / 出 / 来一篇 / 做一条 / 润色 / 扩写 / 重写 / 改 / 换标题 | +20 |
| `L1.object` | 笔记 / 脚本 / 文案 / 标题正文 / 三版 / 版本 / 分镜 / 口播稿 / 视频脚本 / 短视频 / 视频 | +15 |
| `L1.brief` | 有产品资料附件 | +25 |
| `L1.commercial` | 商单 / 合作 / 推广 / 报备 / 挂车 / brief / 品牌方 / 甲方 | +20 |
| `L1.spec` | 3 篇 / 3 版 / 三条 / 30 秒 / 15 秒 / 60 秒 / 带话题 / 带标签 | +10 |
| `L1.entity` | 命中已知品牌或产品实体 | +10 |

### 第二层：关键词密度（累加，封顶 30）

| 信号 | 计算方式 | 封顶 |
|---|---|---|
| 创作动词族 | 每命中 1 个不同动词 +8 | 16 |
| 内容要素词 | 卖点 / 人群 / 场景 / 成分 / 价格 / 测评 / 口感 / 性价比 / 转化 / 种草 / 镜头 / 口播 / 完播 / 分镜 / 咖啡；每满 2 个 +3 | 9 |
| 平台词密度 | 小红书 / 抖音 / 图文 / 视频 / 话题标签，不同组 ≥2 个 +5 | 5 |

### 第三层：扣分（累加，总分不低于 0）

| 扣分 | 命中条件 | 分值 |
|---|---|---|
| `P.method` | 方法论 / 规则提问（起号 / 涨粉 / 违规词 / 几点发 / 限流 / 完播率 / 投流） | −25 |
| `P.evaluate` | 诊断诉求且无创作动词（帮我看看 / 分析 / 诊断 / 复盘 / 为什么没流量） | −20 |
| `P.chat` | 寒暄或闲聊（你好 / 在吗 / 谢谢 / 天气 / 好困） | −40 |
| `P.weak` | 只有平台词，没有产出对象或创作动词 | −10 |

**总分** = 第一层（≤65）+ 第二层（≤30）− 扣分，取值 0–95。

## 5. 阈值与例外

| 总分 | 决策 | 行为 |
|---|---|---|
| ≥ 70 | 直接触发 | 不再问「是否要写脚本」 |
| 40–69 | 待判 | 调 LLM 二判（`temperature=0`，只答是/否）；「是」触发，「否」按日常问答 |
| < 40 | 不触发 | 按日常问答；可在末尾补一句「需要的话我可以帮你写成图文或分镜」 |

**三个例外**：

1. **带 brief 的商单**落在 40–69：直接触发，无需二判。
2. **强形态词 + 创作动词**：`分镜 / 口播稿 / 视频脚本 / 短视频` 直接走视频分支，不受 40 分限制。
3. **明确的小红书图文创作**落在低分：只要有创作动词 + 图文对象，走图文分支，不硬压成闲聊。

**为什么阈值仍取 70**：两条路的误判代价不对称。把闲聊判成脚本，用户会被硬塞进七步流程；把脚本判成闲聊，用户补一句「帮我写」即可恢复。所以入路门槛从严，宁可多问一句。

## 7. 校准方法

1. 收集 30–50 条真实用户输入，人工标注 `intent + modality + branch`。
2. 跑 `python3 scripts/intent_score.py --eval references/shared/intent-cases.jsonl`，看准确率与错例。
3. 优先修**形态门**错误：把视频判成图文、或未指定平台却直接生成，返工成本最高。
4. 再调扣分项（误判主要来自方法论与评估），最后才动第一层权重和阈值。
5. 每次调整后更新第 6 节基线表，否则回归无据可依。
