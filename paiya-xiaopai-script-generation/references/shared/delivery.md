# 展示、成品卡与定点改写（共用）

## 1. 展示顺序

统一顺序：**选题门（3 条候选等用户选）→ 对话内三版可复制块 → 需要并排比较时再出卡片页 → Markdown 成品卡留档**。

还没选题就展示脚本，等于替用户做了决定；选题前不要装配骨架、不要生成正文。

不要把整份 Markdown 直接甩给用户，也不要用 HTML 代替对话展示。

## 2. 对话内可复制块

### 2.0 选题门（两分支共用）

```text
【本轮热点】10 元内自制拿铁（飙升榜第 3 · 搜索词 · 有效至 11-26 12:00）

1｜平价替代：10 元内自制拿铁：用平价替代算一笔账
   理由：飙升榜第 3；粉丝 46% 在 24–30 岁；清单占历史 35%
2｜对比测评：10 元内自制拿铁：用对比测评挑值得的那款
   理由：……
3｜教程步骤：10 元内自制拿铁：用教程步骤复刻一遍
   理由：……

回复 1 / 2 / 3，或「选第 2 条」。
```

### 2.1 图文分支

每版一个纯文本代码块，卡头带骨架 ID 与形态，块内按标题 / 封面 / B1–B6 / 标签 / 配图排列：

```text
【V1｜测评·冲突】xhs_5b21c7e4｜PASS｜正文 416 字｜主推：价格 + 成分
标题：T1 主标题（备选 T2 / T3）
封面：C 大字 + 副标

B1 …
B2 …
B3 …
B4 …
B5 …
B6 …

标签：#…
配图：P1 … / P2 …
```

按 V1 → V2 → V3 排列，块间空一行；完整质检清单留在 md。

### 2.2 视频分支

每版一个纯文本代码块，块内一镜两行：

```text
【V1｜测评·结论前置】dy_9d3f61ab｜30s · 9:16 · 10 镜 · 口播 109 字 · PASS
主推：首创 / 21亿杯｜结尾：产品 + APP当日价

S1｜0-3s｜近景｜画面：…
台词：…｜字幕：…｜音效：…｜转场：硬切
```

按 V1 → V2 → V3 排列，末尾附拍摄清单。完整 9 列表格留在 md；用户说「看 V2 全部」再单独展开。

## 3. Markdown 成品卡

文件名：

- 图文：`小红书脚本_<产品名或主题>_<YYYYMMDD>.md`
- 视频：`抖音视频脚本_<产品名>_<YYYYMMDD>.md`

### 3.1 图文成品卡

```markdown
# 小红书脚本_<产品>_<日期>

## 元信息
## 选题与骨架（热点 5 选 1、3 条候选与选定、3 条骨架与改造清单）
## 装配摘要（画像 / 热点 / brief，含降级说明）
## 三版脚本（### V1｜… / ### V2｜… / ### V3｜…，每版标注骨架 content_id）
## 质检报告（逐版结论 + 命中位置 + 建议替换）
## 版本链
## 依据链
## 待补充项
```

### 3.2 视频成品卡

```markdown
# 抖音视频脚本_<产品>_<日期>

## 元信息
## 选题与骨架（热点 5 选 1、3 条候选与选定、3 条骨架与改造清单）
## 装配摘要（画像 / 热点 / brief，含降级说明）
## 三版脚本（### V1｜… / ### V2｜… / ### V3｜…，每版标注骨架 content_id）
## 质检报告（逐版结论 + 命中清单 + 数字人工判定）
## 版本链
## 依据链
## 待补充项
```

## 4. 版本链

每次改写形成新版本，旧版保留可回退：

```text
V1（初稿）→ V1.1（改标题）→ V1.2（B3 缩短）
V2（初稿）→ V2.1（S8 转场改甩镜）
```

版本链记录：

- 触发改写的用户原话；
- 命中的锚点 / 镜号 / 秒数；
- 改动摘要（改了什么、没改什么）；
- 改写后质检结论。

## 5. 定点改写

### 5.1 图文锚点

| 用户说法 | 锚点 |
|---|---|
| 改第一个标题 | `V1-T` |
| 第二个语气太硬 | `V2` 全局语气 |
| 第三版第 2 段太长 | `V3-B2` |
| 换个开头 | 当前版 `-B1` |
| 标签再加两个 | `-H` |

### 5.2 视频锚点

| 用户说法 | 锚点 |
|---|---|
| 改第一个的标题 | `V1-COVER` |
| 开头再抓人一点 | `V1-HOOK`（只改 S1） |
| 第 3 秒到第 5 秒表情丰富点 | 按时间码落到 `V{k}-S{n}.visual` |
| 第二个视频口播太快 | 该版所有 `S{k}.line` 缩短，同步压字数 |
| 把价格提到前面 | 迁移价格句到更早镜头，标注移动而非新增 |
| 换 BGM | 该版音效 / BGM 列整列替换 |
| 改 S8 转场 | `V2-S8` 的转场单元格 |

**铁律**：

1. 只改被点名的锚点，其余逐字不变；
2. 秒数落在空档、版本不存在、指代有歧义 → 回问一句，不猜；
3. 改完立即跑该版质检，结论写进版本链；
4. 需要联动（改台词导致字数超限）时，只压该镜字幕或拆镜，不重写全篇。

## 6. 交付检查

- 是否先给了 5 选 1 的本轮热点与 3 条候选，并等用户选定；
- 成品卡是否记录了选定选题、3 条骨架 content_id 与改造清单；
- 对话内是否给了三版可复制块；
- 每版是否带质检结论；
- 成品卡是否写了降级说明与依据链；
- 版本链是否记录了本轮改动；
- 需要比较时是否生成了卡片页，且 3 个版本都在。
